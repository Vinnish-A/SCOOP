# Observed failures and their disposition

This archive separates demonstrated failures from suggestions. A documented
workaround, a source patch, an installed release and a scientifically resolved
result are distinct states. Project-specific evidence stays with the project;
this file records reusable causes and the implemented product boundary.

| Observed failure | Root cause | Product repair | What it cannot establish |
| --- | --- | --- | --- |
| Root help hides routed analysis commands | Discovery/parser names differ from the actual semantic router | Expose routed commands and their nested actions | Doctor/help cannot prove a backend succeeded |
| A successful no-output command becomes committed | Exit status is used as analysis qualification; old directories are inventoried as outputs | Separate execution, validation, interpretation and coverage; declare artifacts; archive prior attempts | A result registrar cannot detect unreported scientific omissions |
| Final delivery silently falls back to QC/programme input | Export scope and annotation completion are implicit | Require reviewed coverage and the selected committed artifact; allow explicit current-state export | Reviewed unresolved cells are not resolved subtypes |
| Rejected reannotation retains old accepted eligibility | Only accepted decisions update annotation status | Revoke affected accepted status; record explicit unresolved decisions and broad/fine scope separately | RNA identity does not assign normality or reference purity |
| A broad RNA identity is recorded as an accepted subtype | A missing scope defaults to fine, or a migration infers granularity from acceptance alone | Default undeclared scope to broad; require explicit fine scope; audit legacy granularity against actual review | Explicitly declaring fine still requires biological adjudication |
| A review template loses its actual DEG table | Evidence bundle does not infer registered marker evidence | Connect registered cluster DEG, require citation, verify cited registered files at commit | Citing a file does not adjudicate its biological interpretation |
| Top marker scores substitute for whole-gene evidence | Export truncation and score-only routes hide negative/untested genes | Export the full tested input axis; keep COSG auxiliary; preserve requested layer and ignore unrelated raw axes | Patient-condition inference needs an appropriate independent design |
| Legacy core fails at Leiden invocation | A function object is passed as an extra positional argument | Remove the extra argument; exercise the wrapper call contract | This regression is not a whole-atlas biological validation |
| Weighted graphs transfer as unit weights | An upstream overloaded graph constructor does not consume the intended values | Use explicit COO triplets and verify weights/checkpoint policy | A technically valid graph can still have unstable biological boundaries |
| Reviewed CNV references disappear | Annotation emits accepted, but a downstream filter admits only labeled | Accept both reviewed status values; retain eligibility/normality rules; reject duplicate genomic analysis names | RNA-CNV neutrality is not proof of DNA normality |
| Spatial masks survive export but not calibration | Source selection is applied after parameter estimation | Join exact source registry rows and apply explicit exclusions before fitting | Unassessed QC fields are not measured passes |
| Rare reference components disappear silently | Backend instance/UMI thresholds filter intended types | Verify retained component axes and require explicit qualification for lost types | Rarity or convergence cannot establish identifiability |
| Count intersections change reference depth | Common-gene counts are renormalized as full-native measurements | Preserve native exposures; allow reviewed native-rate caches | Missing measured genes cannot be restored by fictional counts |
| A fitted model must rerun after a save error | Fitting and export share a single completion boundary | Commit input/code/package-bound numerical checkpoints before export | Reusing a fit does not approve its science |
| Cellwise records, cluster identities and reference eligibility share one completion flag | Scope and measured unit are absent from status | Explicit broad/fine and result coverage; bind consumed decisions/receipts as inputs | Four million reviewed source views need not be four million independent biological cells |
| A small residual lineage hides inside a large parent | Sampling coverage and whole-parent evidence are extrapolated to a changed residual subset | Revisit exact residual membership, source/unit coverage and competing native features before qualification | Source limitations cannot excuse an unperformed analysis |
| Whole-transcriptome programme projection is called whole-transcriptome discovery | A full projection axis obscures a restricted discovery basis | Report both axes and run an informative bounded discovery sensitivity when needed | An absent loading is not absence of a lineage marker |
| NMF consensus looks stable despite inconsistent seeds | Unconstrained clustering counts same-seed duplicates and assigns singleton stability one; a median hides weak components | One-to-one cross-seed alignment, per-component scores and minimum-component K qualification; single-seed stability unassessed | A stable factor is not a biological identity, and stability is separate from optimizer convergence |
| Methods disagree but references/features changed together | A workflow sensitivity is interpreted as an isolated algorithm comparison | Support fixed shared genes and registered same-signature controls | Method-specific calibration/background/priors and absent ground truth remain explicit |

Known external or project-specific limits remain open where relevant: inaccessible
raw measurements, conflicting spatial geometry versions, missing event fields,
unverified capture-library identities, historical gene aliases, and missing
objective traces from past unlogged epochs. Recovered native files and verified
QC/checkpoints should be reused; a status migration must not invent those data
or erase the failed attempts.
